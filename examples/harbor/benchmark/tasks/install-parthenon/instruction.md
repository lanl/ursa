Install LANL's Parthenon adaptive mesh refinement framework from its official
`lanl/parthenon` GitHub repository in this Red Hat UBI 10 Minimal environment.
Clone it to `/opt/parthenon`, configure a release build in
`/opt/parthenon/build`, and successfully build the Parthenon library. Leave the
source and build products in place for verification. You may install required
build dependencies. Do not substitute the unrelated PyPI package named
`parthenon`.
